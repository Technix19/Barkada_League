# Barkada League — Links

- **Repository:** https://github.com/Technix19/Barkada_League
- **Live site:** https://barkada-league.vercel.app
- **API:** https://barkada-league-api.onrender.com (health check:
  [`/api/health`](https://barkada-league-api.onrender.com/api/health))

The frontend is deployed on Vercel and the backend on Render; the backend is
on Render's free tier, so it spins down after inactivity and the first
request after a quiet period can take 50+ seconds.

See the root [README.md](../README.md) for setup instructions, the API route
table, and the project structure. See [REPORT.md](REPORT.md) for the Week 2
change log and [SECURITY-CHECKLIST.md](SECURITY-CHECKLIST.md) for the
security review.
